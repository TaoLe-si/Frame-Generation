## FG 接入实现（2026-09-17 第二轮）
原生层：`native/src/dlssmc_fg.cpp` → `dlssmc_fg.dll`（9 个 JNI 导出，只依赖 sl.interposer.dll）
- Vulkan 设备 + 在 MC 的 HWND 上自建 swapchain 接管上屏
- 三张 GL 纹理经 WGL interop(SHARED/KMT) → `VK_EXTERNAL_MEMORY_HANDLE_TYPE_D3D11_TEXTURE_KMT_BIT` 导入
  - finalTex = 主 target 颜色（世界+手持+HUD）
  - hudlessTex = 画 HUD 之前的画面（在 `GameRenderer.renderLevel` 世界调用返回后拷一份）
  - depthMvTex = R=深度 GB=相机运动向量（复用 SR 的 DepthMotionPass）
- 每帧：blit finalTex→swapchain 图像 → 打三份 tag → slSetConstants → slDLSSGSetOptions → slEvaluateFeature → Present
- Reflex 标记（PCLMarker）+ `slDLSSGGetState` 回报实际呈现帧数

Java 侧：
- `DLSSFGNative`（JNI 桥）、`FGRuntime`（调度）
- `MixinWindow`：`@Redirect` 掉 `Window.updateDisplay` 里的 `RenderSystem.flipFrame`，改由我们上屏
- `MixinGameRenderer`：世界渲染结束后调 `FGRuntime.captureHudless()`
- 配置改为 `FRAME_GEN` 枚举（OFF/X2/X3/X4），SR 的 `mode` 默认 OFF 已冻结
- Sodium 设置页选项换成帧生成档位

## 实机调试第二轮（黑屏 / 卡顿）
修掉的：
- **熔断**：初始化失败不再每帧重试（原来每帧重建整套 GPU 设备，卡到没法玩）
- **顺序**：Vulkan 设备必须先于 D3D11 设备创建，否则 SL 把它当 D3D11 应用，`vkCreateDevice` 反复失败 + swapchain 0 张图
- **`eUseFrameBasedResourceTagging`**：不加的话每帧 `slSetTagForFrame` 返回 19
- **backbuffer tag**：DLSS-G 需要它传尺寸/格式，缺了会报 `Invalid backbuffer resource extent (0 x 0)`
- **`consts.cameraPinholeOffset`**：不设 SL 会警告
- **GL flush**：吞掉 `flipFrame` 后必须自己 `glFlush()`，否则互操作读到空画面
- **多帧并行**：3 帧 fence/semaphore 环 + `slReflexSleep`
- 每帧日志限流（原来每帧 3 行带 fflush）

## 黑屏 / 卡顿 / 帧率无变化 —— 定位与修复
### 已修复
1. **卡顿**：初始化失败每帧重试（每帧重建整套 GPU 设备）→ 加了熔断 + 5 秒冷却
2. **顺序**：Vulkan 设备必须先于 D3D11 设备创建，否则 SL 把它当 D3D11 应用（`vkCreateDevice` 反复失败 / swapchain 0 张图）
3. **`eUseFrameBasedResourceTagging`**：不加则每帧 `slSetTagForFrame` 返回 19
4. **backbuffer tag**：DLSS-G 需要它传尺寸/格式
5. **`consts.cameraPinholeOffset`**：不设会有警告
6. **黑屏**：根因是互操作要求 GL 写入发生在**锁定窗口内**。改成
   lock → GL 拷贝/渲染 → glFinish → unlock，并自建普通 GL 纹理（不注册 MC 主 target）
7. **`nativeUnlock` 从未真正解锁**（被一条过宽的 sed 误注释掉），导致后续 nativeLock 全失败
8. **每帧日志限流**：之前 177 万条 GL 错误 + 532MB 日志文件，本身就是卡顿源

### 帧率无变化的原因
NGX 建特性失败 → 帧生成没真正跑起来 → 渲染路径与原版一致，帧率当然一样。

### 当前唯一卡点
`NGX create feature failed 0xBAD00002` = `NVSDK_NGX_Result_FAIL_PlatformError`。
SL 日志一直报 Vulkan 钩子挂不上（CmdBindPipeline / CmdBindDescriptorSets / BeginCommandBuffer
都是 "NOT supported, plugin will not function properly"）。
原因：Vulkan 下不该静态链接 sl.interposer.lib，应动态加载 sl.interposer.dll 并**经它的
vkGetInstanceProcAddr / vkGetDeviceProcAddr 获取所有 Vulkan 入口点**（官方 manual hooking 文档）。
